## 🎯 Project goal

Create a calm and understandable journey from discovering the catalogue to reviewing a completed order.

The interface prioritises sequence and clarity instead of placing too many elements on one screen.

## 🧭 Customer journey

1. 🥖 open the catalogue;
2. 🔎 select a product;
3. 🧺 add items to the cart;
4. ✏️ adjust quantities;
5. 🧾 complete the checkout steps;
6. ✅ review the order.

## 🧩 Key states

- catalogue and product cards;
- shopping cart;
- quantity controls;
- step-by-step checkout;
- hints and errors;
- validation states;
- responsive layout.

## 🔐 Order verification

### 🧮 Recalculation

The final total is recalculated on the server instead of trusting client-side values alone.

### ✅ API validation

Incoming order data is validated again before processing.

### ♿ Accessibility

The interface is designed so that states, messages and controls remain understandable beyond purely visual presentation.

> ℹ️ This is a demonstration project. Real payment and order submission are disabled.
